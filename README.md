## What It Does

Among Us Trainer is an HTML game utility designed for training and helper-focused use in Among Us. Its main purpose is to provide configurable visibility and movement controls for exploring match behavior and social-deduction gameplay.

Available functionality includes ESP-style player visibility, impostor role identification, teleport controls, movement-speed adjustment, kill-anywhere behavior, and cosmetic unlocking. Future revisions are expected to track changes in the HTML environment and the hooks or inputs exposed by it.

## Available Features

- **ESP wallhack:** Provides additional visibility during gameplay
- **Impostor reveal:** Helps identify impostor roles when supported
- **Kill anywhere:** Allows interaction beyond normal restrictions
- **Teleport:** Quickly relocates the player to a chosen position
- **Speed hack:** Changes the player's movement speed
- **Unlock cosmetics:** Provides access to cosmetic content
- **HTML support:** Intended for browser-based game builds
- **Trainer interface:** Organizes controls for quick option changes
